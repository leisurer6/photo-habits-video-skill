# 摄影习惯数据视频

把照片库变成可追溯的统计和数据动画。先弄清数据覆盖范围，再制作；照片文件数、去重后的拍摄记录数和实际拍摄行为并不完全相同。

## 按用户当前阶段工作

- 只要统计：读取、去重、展示数据并保存结果，完成后停在统计阶段。
- 先敲定、等“开始”：可以进行用户已授权的统计和方案准备，必须等到用户明确开始后才生成视频或付费图像。已给出的开始指令持续有效，无需重复确认。
- 已授权制作：沿用已确认的画幅、长度、字幕、音乐、画面风格和照片展示偏好，完成预览、导出与验证。新增缺失信息不妨碍独立部分继续制作。
- 新增硬盘或目录：保留旧数据和版本，以独立批次增量合并；不重新解释用户已确认的疑似重复处理决定。

无明确偏好时，可建议 35 秒概览或 60 秒扩展版、16:9、中文字幕、深色底白字青蓝图表、轻节奏音乐和无旁白。这些是可修改的建议，不是要求。是否展示个人照片单独遵从用户选择。

## 先统计并展示依据

使用 `scripts/photo_stats.py`；运行前查看相应子命令的 `--help`。扫描依赖 ExifTool，分析使用 Python 标准库。详细方法见 [EXIF、增量与去重](references/metadata-and-dedup.md)。

1. 为每块物理盘或导入批次设置稳定、唯一的 `batch-id`，记录根目录。盘符和同名路径可能被另一块硬盘重复使用，不能充当全局身份。
2. 读取原文件 EXIF，保留原始字段、来源、子秒、时区和必要的哈希证据；不修改照片。目录列表、网盘缩略图或文件上传时间不能代替原图 EXIF。
3. 内容哈希相同可以合并。RAW/JPG 或改名副本按参考中的证据分层处理；同名且参数不同必须分别保留。只因参数相似、尺寸变小而疑似重复的记录，默认分别保留并标记。
4. 计算焦距、光圈、ISO、快门、机型、镜头、24 小时、每年每月与拍摄天数。每项占比使用该项有效值作分母，并报告覆盖率。镜头实际焦距与 35mm 等效焦距分别说明，不混算。
5. 展示主要发现、日期范围、去重数量、缺失值、疑似重复和年份覆盖缺口。相机时钟异常仅在有依据时排除出时间统计，不能随意删掉其曝光参数。
6. 保存原始元数据、合并记录、统计、去重决定和报告。备份可重跑的数据与证据；源照片仍留在原位置。

网盘只能通过已授权连接、正常分享下载或本地同步目录访问。需要登录且当前工具不能访问时，说明缺口，继续可完成的本地部分；不绕过登录，不把“已看到目录”说成“已读取照片”。

## 把已审核数据变成动画

使用 `scripts/render_video.py`，把 `summary.json` 作为唯一数据输入；不要把这次项目的机型、计数、年份或缺失情况写死为后续任务默认值。详细分镜、可选贴图和验收见 [视频与设备素材](references/video-design.md)。

- 数据条形图、计数和比例来自当前统计。数据不足时显示缺失状态或省略该章节，不用演示值冒充结果。
- 光圈动画孔径随 `1 / f 值` 变化；低 f 值对应大孔径。太阳月亮可表示时刻，不能在缺乏位置与日期计算时宣称真实日出日落。快门轨迹是曝光时间示意，需标明其示意性质。
- 年月热力图如果各年独立归一化，应明确标注，并保留实际计数；跨年总量另列。照片张数与拍摄天数分别表达。
- 设备贴图属于可选增强。用户需要时核对官方产品图的型号、代际、机身/套机和镜头卡口。只有具备图像编辑工具且符合预算时，才制作官方图衍生风格贴图；缺工具时使用文字和图表，并如实说明。程序叠加名称和数据，避免依赖生成图里的文字。
- 优先复用本地渲染；先看预览帧再全片导出。使用有权使用的音乐或可复现的合成音乐；无可用音频时说明并输出静音版。不得宣称未加入的音乐或贴图已经完成。

## 交付与保存

交付可播放的 MP4、必要的字幕、统计报告和可重跑的数据备份；注明未纳入的来源与有意义的统计限制。解码检查时长、分辨率、帧率、字幕可读性及音频，重点检查跨章节转场和长标签是否遮挡。

默认将用户数据、日志、下载素材和生成视频放在本地运行目录，不自动提交 Git。发布技能代码不等于授权公开照片、EXIF、原始路径、设备序列号、定位、云盘分享链接、提取码、Cookie 或密钥。只发布代码、必要说明和明确标识的合成演示数据。
