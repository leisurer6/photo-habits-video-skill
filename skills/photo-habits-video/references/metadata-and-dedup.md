# EXIF、增量与去重

需要扫描照片、新增硬盘、修复异常字段或解释统计口径时读取本文件。

## 本地工具与保存结构

以 ExifTool 读取 JPG/JPEG、HEIC、常见 RAW 等格式的元数据，不解码或修改整张照片。独立可执行版直接传给 `--exiftool`；Perl 脚本版同时传 `--perl`。扫描命令的多个 `--root` 属于同一来源批次。

```text
photo_stats.py scan --root PATH --batch-id NAME --output SCAN_DIR --exiftool EXIFTOOL
photo_stats.py analyze --input SCAN_DIR/metadata.json --output RUN_DIR
photo_stats.py analyze --input NEW_SCAN/metadata.json --baseline PREVIOUS_RUN --output NEW_RUN
```

运行前用 `--help` 核对实际扫描输出文件名；将输出的元数据 JSON 传给分析命令。`--baseline` 是前次分析目录。所有运行目录应留在 Git 忽略范围或仓库外。

分析产物：`metadata_all.json` 保存合并来源；`records.json` 保存去重后的拍摄记录；`summary.json` 提供统计；`duplicate_candidates.json` 记录疑似项；`duplicate_decisions.json` 保存处理决定；`report.md` 提供可读解释。批次或文件身份变化时，保留旧版本而不是覆盖历史。

## 来源身份

每个源记录身份至少由导入批次与批次内路径确定。记录文件大小和修改时间用于核对扫描状态；这些不是拍摄时间。能够取得物理盘卷标、卷标识时可留作证据，但不要把平台特有信息变成跨平台依赖。

同一盘再次扫描应复用正确批次身份；另一块盘即使也挂载为相同盘符且存在同名目录，也要新建批次。新增来源先与保留的数据合并，再运行统计，不能只把汇总数字相加。

## 去重证据

按强弱使用证据，并保存合并原因：

| 证据 | 处理 |
| --- | --- |
| 原文件完整内容哈希相同 | 可合并，保留所有来源 |
| 同一拍摄的 RAW/JPG，完整时间含子秒、机型、焦距、光圈、ISO、快门等一致，且文件关系与上下文支持 | 可归为一个候选拍摄记录，保存比较字段与来源 |
| 同名但拍摄时间、子秒或核心参数不一致 | 分别保留 |
| 改名、缩小、转存，部分 EXIF 一致但缺失子秒或证据不足 | 标记疑似，默认分别保留；由用户决定是否合并 |
| 仅文件名、尺寸、文件创建时间相同 | 不足以合并 |

子秒不能在解析时截掉；缺失子秒不等于 `000`。知道双方时区、镜头或其他可区分字段时也要比较。连拍可能共享秒级时间和全部曝光参数，因此跨目录的秒级元数据相同不能自动证明同一张。手动镜头的 `0 mm`、`f/0` 是未知值，不是可用于确认重复的参数。

`--hash-mode candidates` 只对本次扫描内同大小的候选文件计算完整内容哈希，用于降低大库读取成本；报告必须说明没有对整库或历史批次完成哈希。`full` 对所有文件计算，适合跨新旧批次核对副本；`none` 不提供内容哈希证据。哈希开销主要是读盘，按用户时间预算选择。

必须继承用户已做出的决定。用户说“先标记并分别保留”后，即使后续重跑，也保留该决定及对应候选身份；若当前脚本没有合并决策的入口，先保留候选，不手工绕开决定。

## 值与时间口径

- 每个字段分别统计有效数和缺失数。ISO 排名的分母是有效 ISO 记录数，镜头排名的分母是有效镜头记录数；不要统一除以总文件数。
- 排除显然无效的非正曝光参数；保留原始值与修正依据。ISO `65535` 可能是编码占位，检查 `RecommendedExposureIndex`、`StandardOutputSensitivity`、`ISOSpeed`、`ISOSpeedRatings` 或制造商字段。只有扩展字段支持时才恢复实际值，不能统一替换成某个高 ISO；无证据时标为未知。
- 优先 `DateTimeOriginal` 及其子秒和偏移，必要时采用有来源说明的其他拍摄字段。没有拍摄时间的记录仍可用于焦距等统计，不进入小时、月度或拍摄天数统计。
- 默认按照片记载的相机本地时间汇总，报告说明口径。没有可靠偏移时不能推断时区，也不能按上传时间、电脑时区或旅行目的地强行修正。要统一时区时需有偏移或用户提供的时间规则。
- 旧日期可能是相机时钟重置，也可能是真实旧照片。只有确认后才用 `--exclude-date` 排除特定日期的时间分析；该选项不应丢弃曝光参数。
- 焦距可选实际焦距或 35mm 等效焦距，先声明口径。机型、镜头规范化需保留原始标签；不能凭模糊 EXIF 名称猜测具体产品代际或卡口。

## 覆盖率与检查

“拍摄记录”是基于现存文件得到的去重候选，不能等同摄影者按快门的全部次数。删除、缺失、网盘未下载和导出副本都会影响覆盖范围。某年或某月没有本地记录应表达为当前素材未记录，而不是断言没有拍照。

至少核对：源文件总数与分组来源对齐、各项覆盖率合理、月度总和与有效日期记录数一致、拍摄天数是日期去重、候选重复未被无意吞并。输出首尾日期，并把用户已知的缺失来源写入报告。年月热力图可按年归一化颜色，但跨年数量比较必须看实数或独立总量图。
