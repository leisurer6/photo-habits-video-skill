# 视频与设备素材

已进入制作阶段，或需要讨论具体视觉方案时读取本文件。

## 从统计选择画面

35 秒适合总览、焦距、光圈、ISO、时段、设备。60 秒可以加入快门、年月分布与镜头。以下是可调整的 60 秒示例，不是固定模板：

| 时间 | 内容 | 动态表达 |
| --- | --- | --- |
| 0–4 秒 | 当前素材日期范围、有效记录数 | 数字递增、时间线展开 |
| 4–10 秒 | 常用焦距 | 排名条形图依次增长 |
| 10–16 秒 | 光圈 | 叶片与孔径变化，旁列真实排名 |
| 16–22 秒 | ISO | 档位分布与常用值 |
| 22–28 秒 | 快门 | 曝光时长与移动光点轨迹示意 |
| 28–35 秒 | 24 小时 | 柱状分布、太阳月亮与天空变化 |
| 35–47 秒 | 每年每月 | 热力格展开、逐年高亮峰值 |
| 47–53 秒 | 相机 | 机型占比、可选机身贴图 |
| 53–60 秒 | 镜头与收束 | 镜头排名、可选贴图、简短总结 |

优先保留能解释摄影习惯的画面，避免把全部数字塞进一屏。字幕陈述明确结论和重要口径，数字只取适当精度。对于缺失数据，减少排名项或显示“无有效记录”，不填演示数值。

## 动效含义

- 光圈：固定同一焦距示意时，开口直径约与 `1/N` 成正比，面积约与 `1/N²` 成正比。`f/1.4` 的开口应比 `f/8` 大。动画内的演示 f 值与统计排名分开标识。
- 日夜：太阳、月亮、星点、天空颜色表示相机记录的时刻。它们是时间示意；要表现真实天文日出日落，需额外的位置、日期和计算依据。
- 快门：同一演示速度下，曝光越长轨迹越长；长短范围很大时可映射到对数尺度并标明示意，不能宣称展示了照片真实运动模糊。
- 月度：各年独立归一化能看清该年旺季，但颜色深浅不能直接比较不同年的总量。每格保留计数，给出图例；不足整年的范围和用户已知缺失应标明。拍摄照片数与拍摄天数可以并列，不能互相替代。

## 可选的官方设备贴图

不需要贴图即可完成数据视频。用户选择贴图后：

1. 从品牌官网核对 EXIF 对应的准确型号、代际、卡口和机身颜色。产品页主图可能是套机、另一卡口或新版，不能仅因标题相似就采用。模糊 EXIF 只显示原始名称或经确认的通用名称。
2. 下载被允许用于本次制作的参考，保存 URL、取得日期、产品名称与卡口。只下载需要的少量主要设备图。
3. 具备 `image_gen` 等图像编辑能力时先查看参考，再做透明底风格贴图。保留产品外形、比例、镜头控制环和辨识特征，以深色阴影、少量青蓝轮廓光适配画面。制作贴图会使用图像生成额度，遵从用户预算与既有授权。
4. 检查透明背景、边缘、产品型号和卡口。名称与计数由渲染程序叠加，不依赖生成图片中的文字。
5. 没有图像工具、预算不足或无法确认型号时使用数据图表与文字。不得把普通图标描述为官方图片衍生贴图，也不能虚报已完成的资产。

官方图片和生成贴图不自动具有可再次分发的授权。为用户本地成片取得的参考不应连同开源技能仓库一起发布；分享资产包或再利用时核对相应权利。技能仓库可以保留不含秘密的来源记录模板，不能上传用户的私人素材。

## 渲染和验收

`render_video.py` 使用 Pillow/NumPy 绘制图表，以 FFmpeg 编码 MP4；可先用 `--preview` 查看抽样帧，再导出完整视频。字体应覆盖中文，找不到时指定 `--font`，避免方块字。FFmpeg 要能编码 H.264；环境没有可用二进制时可使用 `imageio-ffmpeg` 提供的版本。

渲染器默认使用本地算法合成轻节奏音乐；`--music` 可替换为用户提供或有权使用的 WAV，`--silent` 则输出无音轨视频。`--preview` 只生成抽样帧、联系表、字幕和清单，不生成音乐或视频。字幕既可烧录在画面里，也可另存 SRT。应以成片音轨检查结果为依据，不能仅凭输入参数宣称已经加入音乐。

最低检查：

- 预览焦距、光圈、ISO、时段、年月与长机型/镜头标签；没有重叠、截断或太小的字。
- 数字、排名和百分比与当前 `summary.json` 一致，必要的分母、部分年份与归一化口径可见。
- 检查开头、每个转场和结尾；看字幕是否有足够阅读时间。
- 解码成片核对时长、宽高、帧率、H.264、可播放性；有音轨时检查时长、音量、淡入淡出和断点。
- 导出新版本时保留前一版；保存本次摘要、素材来源、渲染参数和当前数据版本，方便新增素材后复用动画。
